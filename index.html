GOOGLE DRIVE

首次設定（只需一次）：本頁需要一個 Google Cloud OAuth 用戶端 ID，先至可以登入 Google Drive。

  1. 到 console.cloud.google.com 建立或選擇一個專案。
  2. 喺「API 和服務 → 資料庫」啟用 Google Drive API。
  3. 喺「OAuth 同意畫面」完成基本設定，並把自己加入測試用戶。
  4. 喺「憑證」建立 OAuth 用戶端 ID（類型：網路應用程式），並喺「已授權的 JavaScript 來源」加入本網頁嘅來源網址（例如 http://localhost:5500；如放上 GitHub Pages 就填 https://你嘅用戶名.github.io，只填到域名，唔使加路徑）。
  5. 把用戶端 ID 貼入 index.html 內 JavaScript 頂部嘅 GOOGLE_CLIENT_ID，然後重新載入網頁。

注意：Google 登入唔支援以 file:// 直接開檔；建議放上 GitHub Pages（自帶 https），電腦同手機瀏覽器都可以正常登入同步。同一個用戶端 ID 可同時加入多個來源網址。

登入 Google 帳戶之後，揀選 Google Drive 上面嘅資料夾儲存 Tasklist 資料。本機仍會保留一份副本，離線都可以照用。

如果本機瀏覽器已登入 Google，彈出視窗會直接列出可選帳戶，撳一下就完成。
